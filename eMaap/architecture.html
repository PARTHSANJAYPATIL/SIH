System Architecture

Technical documentation and security framework

1. System Overview

eMaap is a web-based platform built with modern web technologies for online verification, digital certification, and lifecycle management of weighing and measuring instruments under the Legal Metrology Act, 2009.

Key Components:

  • Web Application: Responsive frontend for desktop and mobile browsers
  • Mobile Field App: Offline-capable inspection recording system
  • Digital Certificate Engine: QR-enabled certificate generation and validation
  • Database: Centralized document storage with encryption
  • API Gateway: RESTful APIs for third-party integration
  • Notification Engine: Email/SMS for alerts and reminders

2. Technology Stack

Frontend HTML5, CSS3, JavaScript (Vanilla/Frameworks)
Mobile Progressive Web App (PWA) with offline support
Backend Node.js/Python REST APIs
Database PostgreSQL / MongoDB (encrypted at rest)
Authentication OAuth 2.0, JWT tokens, LDAP integration
Hosting Government Cloud (GCCP / AWS GovCloud)
Certificates QR Code Library (qrcode.js), Digital Signing

3. Security Framework

Data Protection:

  • Transport Security: HTTPS/TLS 1.2+ for all communications
  • Data Encryption: AES-256 encryption for sensitive data at rest
  • Database Security: Row-level security, encrypted backups
  • Field Data: Local encryption before sync with cloud

Access Control:

  • Role-Based Access Control (RBAC): User, LMO, GATC, Admin roles
  • Multi-Factor Authentication: OTP via SMS/Email
  • Session Management: Token expiry, concurrent session limit
  • Audit Logging: All actions logged with timestamps and user info

Digital Certificates:

  • Certificate Signing: Digital signature with private key
  • QR Code Authentication: Unique hash per certificate
  • Tamper Detection: Hash verification on public search
  • Non-Repudiation: Officer signature binding

6. Deployment & Availability

  • Server: Auto-scaling on cloud infrastructure
  • Availability: 99.9% uptime SLA with redundancy
  • Backups: Daily encrypted backups with point-in-time recovery
  • Disaster Recovery: RPO 1 hour, RTO 4 hours
  • Load Balancing: Geographic distribution across data centers
  • CDN: Static assets cached globally

7. Compliance & Standards

  • Legal Metrology Act, 2009 & Rules, 2011

  • NIST Cybersecurity Framework

8. Scalability & Performance

  • Database: Sharding by state for distribution
  • Caching: Redis for session and certificate cache

  • Page Load: Target < 2 seconds for all pages
  • Mobile App: Works on 2G+ networks with offline sync
  • Concurrent Users: Support 100,000+ simultaneous users
